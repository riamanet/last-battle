# LAST BATTLE

라스트 어사일럼: 페스트 225~256 서버의 영웅 총투력을 내 캐릭터와 비교하는 모바일 웹사이트.
화면, API, 자동 수집이 모두 `worker.js` 하나(Cloudflare Worker + D1)에 들어 있다.

## 데이터가 채워지는 방식

| 데이터 | 출처 | 주기 | Tracker API 차감 |
| --- | --- | --- | --- |
| 서버별 영웅 총투력 상위 100명 | LastAsylum.gg 공개 랭킹 페이지 | 서버마다 12시간에 1번 (Cron이 15분마다 1개 서버씩) | 없음 |
| 전체 투력(활동 추정용) | Tracker 길드 API | 랭킹에 오른 인원이 많은 길드부터 하루 1번, 하루 최대 320회 | 길드당 1회 |
| 특정 유저의 최신 영웅 총투력 | Tracker 유저 API | 화면에서 "갱신"을 눌렀을 때만 | 1회 |

- 접속, 서버 선택, 검색, 정렬은 저장된 데이터만 읽는다. API가 차감되지 않는다.
- 아직 수집되지 않은 서버를 고르면 그 자리에서 공개 랭킹을 읽어 온다.
- 영웅 총투력은 Tracker로 읽은 값과 공개 랭킹 값 중 더 최근에 읽은 쪽을 보여 준다.
- 하루 1,000회 한도 중 자동 수집 320회와 예비 50회는 수동 조회가 쓰지 못한다.

## 활동 추정

접속 여부가 아니라 전체 투력이 변했는지를 본다.

| 표시 | 의미 |
| --- | --- |
| 초록 | 최근 24시간 안에 전체 투력 변동을 관측 |
| 노랑 | 1~2일 미변동 |
| 주황 | 3~6일 미변동 |
| 빨강 | 7일 이상 미변동 |
| 회색 | 기록 없음, 수집을 시작한 지 하루가 안 됨, 또는 수집이 이틀 넘게 밀림 |

길드가 없거나 길드 수집 순서(하루 320곳)에 들지 못한 유저는 회색으로 남는다.

## 배포와 설정

`main` 브랜치에 올리면 Cloudflare Workers Builds가 `npx wrangler deploy`로 배포한다.

- Secret: `ADMIN_PASSWORD`, `TRACKER_API_KEY`
- D1 바인딩: `DB`
- 테이블은 첫 요청 때 자동으로 만들어지고, 이전 버전 테이블은 그대로 이어 쓴다.

관리자 비밀번호로 한 번 접속하면 그 기기에서 30일 동안 유지된다. 비밀번호나 API 키를 바꾸면 모든 기기에서 다시 접속해야 한다.

## 테스트

Node.js 22.5 이상에서 실행한다. D1과 외부 사이트를 가짜로 대신하므로 API가 차감되지 않는다.

```
node --test test/worker.test.mjs
```
